# Как это учить?
На основании документы "Этапы выполнения итогового проекта", выполнить работу над индивидуальной темой проекта.

# Описание общих порядков действий

1. На основании итогового проекта "Основы анализа и проектирования баз данных", произвести пошаговое выполнение всех этапов;
2. Произвести установку и конфигурацию СУБД PostgreSQL и MySQL;
2.1. Ссылка на скачивание дистрибутива PostgreSQL - https://www.postgresql.org/download/
2.2. Ссылка на скачивание дистрибутива MySQL - https://dev.mysql.com/downloads/installer/
3. Выполнение работы вольное, либо начать с СУБД PostgreSQL (этапы с 1 по 21), либо начать с MySQL (этапы с 22 по 41).

# Описание этапов выполнения

- Инструкция по установке находится в файле "Этапы выполнения итогового проекта", перед описанием основных этапов;
- Для сдачи этапов 1-14, 16-34, 36-41 - предоставить документ MS Word + файлы скриптов с расширением SQL;
- Для сдачи этапов 15 и 35 - предоставить документ MS Word;
- В архивах *.zip лежат скрипты, баз данных, которые указаны в файле "Этапы выполнения итогового проекта", которые можно запустить, и выполнить посмотреть принцип работы.
