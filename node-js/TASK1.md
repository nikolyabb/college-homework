1.     Установите Node.js. Убедитесь, что Node.js установлен и продемонстрируйте это;

2.     Вывести в командной строке «Hello World» в режиме REPL;

3.     Воспользоваться одной из математических функций на ваш выбор (возведение в степень, найти квадратный корень из числа, найти натуральный логарифм числа или воспользоваться любым другим методом объекта Math);

4.     Выполните код из созданного файла при помощи командной строки;

5.     Ознакомьтесь со списком глобальных объектов JavaScript воспользовавшись необходимой командой в командной строке;

6.     Выберите один из стандартных объектов JavaScript (можно воспользоваться информацией, полученной в пункте 5) и при помощи REPL выведите список его свойств и методов;

7.     Запросите у пользователя имя и затем вывести приветствие с личным обращением по имени (код пишете в командной строке!);

8.  Создайте новую папку и в ней новый файл app.js - работаем с модулями;

9.  Подключите модуль http.  Создать новый сервер для прослушивания входящих подключений и обработки запросов;

10.  Запустите сервер через командную строку;

11.  Откройте браузер и введите в адресную строку адрес http://localhost:3000/;

12.  При помощи модуля os получить имя текущего пользователя;

13.  Создайте собственный модуль, который будет содержать в себе стрелочную функцию. Результатом работы функции должен быть синус числа х;

14.  Выведите в командной строке дату и время запроса;

15.  Выведите приветствие с обращением по имени пользователя ПК. Если приветствие выводится утром, должно быть выведено «доброе утро», если днем - «добрый день», если вечером – «добрый вечер»;

16.  Вывести приветствие с обращением по имени. Имя должно быть определено в отдельном файле;

17.  Вывести приветствие с обращением к двум разным людям, пользуясь кэшированием модулей;

18.  Поработайте со структурой модулей: создайте три новых файла в подкаталоге, затем выведите два приветствия;

19.  Установите глобальную переменную date;

20.  Получите глобальную переменную name, которая установлена извне;

21.  Передайте приложению параметры, например имя и возраст (или любые другие на ваше усмотрение);

22.  Установите последнюю версию пакетного менеджера и зафиксируйте результат (информацию о текущей версии npm);

23.  Создайте проект и добавьте в него файл package.json;

24.  Установите фреймворк express;

25.  Зафиксируйте изменения, произошедшие в файле package.json;

26.  Добавьте в проект файл app.js для определения простейшего сервера.  Воспользуйтесь методом app.listen() для того, чтобы сервер начал прослушивать подключения;

27.  В адресной строке браузера введите адрес http://localhost:3000/ и зафиксируйте результат;

28.  Добавьте несколько пакетов, например пакеты, представляющие библиотеку React;

29.  Добавьте пакет, используемый для тестирования приложения, в секцию devDependencies;

30.  Удалите пакет express;

31.  Удалите несколько пакетов;

32.  Создайте команды в файле package.json для получения переданных при запуске приложения параметров.
