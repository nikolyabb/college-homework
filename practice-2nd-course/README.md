# Описание  
Это учебный проект для Практики 2го курса ITHUB направления фронтенд-разработка.  
Наша задача сделать прототип чат-бота с базовой функциональностью по  выполнению арифметических операций с двумя числами.  

# Запуск приложения  
Приложение не требует настроек.  
Для запуска приложения достаточно открыть файл index.html из текущей папки в любом браузере или использовать статическую ссылку на Gihub Pages где приложение уже развернуто и готово к использованию.

[Ссылка на Github](https://nikolyabb.github.io/college-homework/practice-2nd-course/index.html)
